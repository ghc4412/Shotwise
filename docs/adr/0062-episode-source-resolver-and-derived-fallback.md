# ADR 0062：统一剧集源文解析与派生文件回退

- 状态：Accepted
- 日期：2026-09-11

## 背景

剧集源文可能来自显式指定的文件、项目账本记录的原文区间，或手动预拆分产生的 `source/episode_N.txt`。如果各入口自行选择路径，规划、拆分、审阅和晋升会对同一集使用不同文本；无原文的手动预拆分项目也无法被后续流程消费。

## 决策

所有需要读取某集源文的入口统一调用 `lib.episode_source.resolve_episode_source`，采用以下顺序：

1. 调用方显式提供的 `source`；
2. `project.json` 对应集的 `source_range`，从归一化原文坐标中切片；
3. 缺省 `source` 时对应集的 `source/episode_N.txt`（包括补零别名）；
4. 没有可用本集派生文件时，回退可发现的原始源文文件，保持旧项目的多文件拼接语义。

所有读取统一使用 UTF-8 和账本的文本归一化规则。账本区间越界或原文不可读时不使用该区间，继续尝试后续候选；显式路径越界或不存在则立即返回可操作错误。手动预拆分回退只读取已有文件，不自动写入 `source_range`，因为它没有可验证的原文坐标。

### 保留的跨文件坐标例外

`episode_planner.py` 和 `episode_reset.py` 不机械迁移到单文件 resolver。规划器需要维护跨文件的连续窗口、cursor、fingerprint 和跨文件坐标；reset 流程需要基于连续性推导 cursor，并判断区间对应的删除或归档边界。这些职责不是单集源文发现或路径归一化，强行复用单文件 resolver 会丢失坐标语义。

这两个模块仍必须共享 source discovery、路径安全检查、UTF-8 读取和文本归一化规则；仅保留各自的跨文件坐标与状态判断逻辑。该边界是有意设计，不表示统一迁移遗漏。

## 后果

- 剧集规划、文本拆分和隔离草稿晋升使用一致的源文选择规则。
- 旧项目和手动预拆分项目无需数据库迁移即可继续消费已有派生文件。
- 缺省源文优先消费本集派生文件，避免把整本原文误交给单集流程；没有本集派生文件的旧项目仍可回退到原始源文拼接。
