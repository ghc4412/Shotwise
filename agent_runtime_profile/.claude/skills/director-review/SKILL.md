# 导演审阅

当用户要求检查已生成的视频片段、确认能否进入成片或进行导演质量审阅时使用本 skill。此阶段只审阅素材，不合成最终视频，也不自动重生成。

## 必须遵循的流程

1. 先调用 `mcp__shotwise__inspect_director_review`。默认审阅当前剧集；用户指定范围时使用 `scope=units` 或 `scope=project`。
2. 先阅读工具返回的 `structured_content`，确认剧本、unit 顺序、确定性 finding、时长汇总和媒体探测状态。
3. 必须实际查看工具返回的每个视频单元的首帧、中帧、尾帧图片。图片前有 `script / unit / position` 标签，不得仅凭 metadata 声称完成画面审阅。
4. 只有首/中/尾帧无法判断镜头运动、动作完成度或转场衔接时，才再次调用工具，对指定 unit 使用 `scope=units`、`include_short_samples=true`；不要默认抽取短采样。
5. 结合剧本的镜头描述与画面，检查：缺镜头、镜头顺序、相邻 unit 连续性、整集人物连续性、整集场景连续性、关键道具连续性、镜头语言是否实现、画面是否符合 shot 描述、总时长与故事节奏。
6. 对无法从帧可靠确认的判断标记为低置信度 `manual_review`，不要把推测写成事实。

## 输出格式

用以下固定结构输出中文导演审阅报告：

- **审阅范围**：剧本/剧集、unit 数量、实际查看的帧范围。
- **结论**：`keep`、`manual_review`、`regenerate` 或 `missing`；说明是否允许进入最终合成。
- **确定性问题**：逐条列出 code、unit、严重程度、证据和建议动作。
- **画面审阅**：按 unit 说明镜头语言、人物、场景、道具、动作连续性；标注置信度。
- **节奏与时长**：规划时长、可用时长、明显过快/过慢或叙事断裂点。
- **重生成建议**：只列出需要用户确认后重生成的 unit，不执行生成。
- **下一步**：若有问题，先让用户确认重生成范围；全部通过后再进入 `compose-video` 或对应导出流程。

## 安全边界

- `regenerate` 只能作为建议，不能自动调用任何生成工具。
- 不修改剧本、unit、资产或项目文件，不保存审阅快照，不写审阅记录。
- 不调用最终合成流程；导演审阅通过后由用户明确要求再进入成片阶段。
- 没有音频流仅作为 `info` 信息项，当前阶段不得因此阻塞或要求重生成。
